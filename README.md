# ⚽ Football Player App

Full-stack football player search application built using:

- Flask
- PostgreSQL
- Docker Compose
- Nginx Frontend

---

# 🚀 Features

- Search players by age
- Search players by kit number
- REST API backend
- PostgreSQL database
- Dockerized multi-container architecture

---

# 🛠 Technologies

- Python Flask
- PostgreSQL
- Docker
- Docker Compose
- Nginx
- HTML / CSS / JavaScript

---

# ▶️ Run Project

```bash
docker compose up -d --build
```

---

# 🌐 Services

| Service | Port |
|---|---|
| Frontend | 80 |
| Backend API | 5000 |
| Adminer | 8080 |

---

# 🔍 API Examples

## Search by age

```bash
/search?age=26
```

## Search by kit number

```bash
/search?number=10
```
