# Football Player App

Full-stack football player search application using:

- Flask
- PostgreSQL
- Docker Compose
- Nginx frontend

## Features

- Search players by age
- Search players by kit number
- REST API backend
- PostgreSQL database
- Dockerized architecture

## Technologies

- Python Flask
- PostgreSQL
- Docker
- Nginx
- HTML/CSS/JavaScript

## Run Project

```bash
docker compose up -d --build
